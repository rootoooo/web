# 洛芮 LORIÉ 婚纱摄影工作室 · 官网

一个纯静态网站，无需任何构建工具，可直接上传 GitHub 并部署到 Cloudflare Pages。
已适配电脑浏览器与手机浏览器。

## 目录结构

```
web-main/
├─ index.html          网站唯一的页面
├─ css/
│  └─ style.css         全部样式
├─ js/
│  ├─ data.js            ★ 图片和文字内容配置（以后主要改这个文件）
│  └─ script.js          页面逻辑（渲染、轮播、弹窗），一般不用改
├─ img/
│  ├─ 00001.jpg ~ 00008.jpg   8 张示例图片（当前都是同一张占位图，替换成真实图片即可）
└─ README.md
```

## 页面功能

1. **顶部胶片式自动轮播**：8 张图片循环向左自动滚动（无限循环，鼠标悬停会暂停）。
2. **点击轮播图片** → 弹出大图 + 标题 + 文字介绍的弹窗（Lightbox），可点击右上角 ×、点击图片外的暗色区域，或按键盘 Esc 关闭。
3. **下方图文介绍区**：每一项都是「左边图片 + 右边文字」，图片会自动适配浏览器宽度；点击图片同样会弹出大图。手机端会自动改为图片在上、文字在下的竖排布局。
4. **关于我们 / 联系我们**：简单的品牌介绍和联系方式区块，方便展示企业信息。
5. 整站已做好响应式适配（电脑、平板、手机），并支持键盘导航、可见的焦点样式。

## 以后如何替换图片和文字（最常用）

打开 `js/data.js`，里面的 `SITE_DATA.items` 是一个包含 8 个对象的数组，例如：

```js
{
  id: "00001",
  file: "00001.jpg",
  title: "皇室玫瑰婚纱系列",
  tag: "BRIDAL",
  desc: "以千朵手工绢花铺陈出如梦似幻的花海布景……",
},
```

- 想换图片：把新图片命名为 `00001.jpg`（沿用编号规则，按顺序编号），放进 `img/` 文件夹替换原文件即可，`file` 字段保持一致就不用改代码；如果换了新的文件名，把 `file` 改成新文件名即可。
- 想换文字：直接修改 `title`（标题）、`tag`（英文小标签）、`desc`（详细介绍）里的文字。
- 想增加/减少作品数量：复制/删除数组中的一整段 `{ ... }`，前面顶部轮播和下面的图文区块会自动一起变化，不需要改 HTML。
- 品牌名称、导航文字、"关于我们"文案、联系方式（电话/邮箱/地址/营业时间），都在 `SITE_DATA` 最前面几项里，同样直接改文字即可。

改完保存文件，直接刷新网页就能看到效果，不需要安装任何软件或运行任何命令。

## 上传到 GitHub

1. 在 GitHub 上新建一个仓库（Public 或 Private 均可）。
2. 把 `web-main` 文件夹里的所有文件（`index.html`、`css/`、`js/`、`img/`）上传到仓库根目录
   （网页端可直接拖拽上传，或者使用 Git 命令）：

   ```bash
   git init
   git add .
   git commit -m "init: 洛芮婚纱摄影官网"
   git branch -M main
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main
   ```

## 部署到 Cloudflare Pages

1. 登录 Cloudflare 控制台 → **Workers & Pages** → **创建应用程序** → **Pages** → **连接到 Git**。
2. 选择刚才上传的 GitHub 仓库并授权。
3. 构建设置保持默认即可（本项目是纯静态 HTML/CSS/JS，**不需要**任何构建命令）：
   - **框架预设**：None / 无
   - **构建命令**：留空
   - **构建输出目录**：`/`（仓库根目录，因为 `index.html` 就在根目录下）
4. 点击 **保存并部署**，几十秒后 Cloudflare 会给出一个 `xxx.pages.dev` 的访问地址。
5. 以后每次给 GitHub 仓库提交新内容（比如按上面方法替换了图片/文字），Cloudflare Pages 会自动重新部署，无需手动操作。
6. 如果你有自己的域名，可以在该 Pages 项目的「自定义域」里绑定，几分钟内即可用你自己的域名访问。

## 本地预览（可选）

不需要任何安装，任意一种方式都可以：

- 直接双击 `index.html` 用浏览器打开；
- 或者在项目文件夹内执行（需要电脑装有 Python）：
  ```bash
  python3 -m http.server 8000
  ```
  然后浏览器访问 `http://127.0.0.1:8000`。
